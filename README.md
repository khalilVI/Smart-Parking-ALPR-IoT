# Smart-Parking-ALPR-IoT

Automated smart parking system featuring Optical License Plate Recognition, IR spot sensors, a servo barrier gate, and a web reservation dashboard. Developed as a 4-month capstone project within the Erasmus+ AfriConnect+ framework.

## 🛠️ Hardware Architecture
* **Sensors:** HW-511 IR spot sensors for vehicle detection
* **Actuators:** MG996R servo motor for the barrier gate mechanism
* **Physical Structure:** Custom 3D printed components (`parking3dprint.stl`)

## 💻 Software Stack
* **Core Logic & ALPR:** Python (`parking_system.py`)
* **Web Dashboard:** HTML/CSS/JS (`index.html`, `admin_panel.html`, `login.html`, `register.html`)
* **Networking:** zrok tunneling for secure, remote dashboard access
